# Security policy

This repository is a synthetic portfolio demonstration. Do not submit real personal,
financial, education, employee, customer, or company-confidential data to its demos.

Report a suspected vulnerability through GitHub's private vulnerability reporting for this
repository. Do not include real sensitive data in an issue, pull request, fixture, screenshot,
or audit log.

The demo does not provide production authentication, authorization, cryptographic human
signatures, secrets management, hardened deployment, or compliance certification. Those are
explicit integration boundaries, not implied features.
