===========================================================

Recorded 2026-09-06T12:53:46+00:00 on Windows 11, Python 3.12.10, from the tree this release was cut from.

HOW THIS BUG WAS FOUND
----------------------
Not by a test. The kind smoke job in CI applied `overlays/dev`, the pod crash-looped,
and `kubectl rollout status` timed out after 180 s. The dump-logs-on-failure step
printed the reason: `SettingsError: error parsing value for field "provider_fallbacks"
from source "EnvSettingsSource"`, from `json.loads("")`. The ConfigMap passes
`ATMPL_PROVIDER_FALLBACKS: ""` to mean 'no fallbacks', and pydantic-settings decodes a
`list[str]` field as JSON before any `mode="before"` validator can see it.

WHAT WAS REMOVED
----------------
src/atmpl/settings.py - `CsvList = Annotated[list[str], NoDecode]` reduced to a plain
`list[str]`, which is what the field was before the fix.
