# Seeded demonstrations

Every organization, person, identifier, application, transaction, and event in this
directory is synthetic and intentionally fake. The three answer packs compile the same
typed artifacts used by the CLI; no demo bypasses discovery validation.

- `retail/`: one base template, EU/US/GCC policy packs, including identical inputs with
  different regional routing.
- `ministry/`: bilingual Arabic/English lesson preparation and inline RTL rendering.
- `bank/`: AI triage drafts with terminal human-only credit authority and an override.
